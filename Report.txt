Introduction
Cryptography plays an important role in modern computer security. It is used to protect sensitive information, verify identities, and ensure that data can be transferred securely across networks. The purpose of this project is to investigate and compare the performance of different cryptographic algorithms using Python. The project focuses on three main areas of cryptography: key establishment, digital signatures, and authenticated encryption. In this Project, I developed a benchmarking program using Python and the `cryptography` library. The program measures how long different cryptographic operations take to complete, allowing their performance to be compared. The algorithms are tested using repeated measurements, with the median and interquartile range (IQR) used to summarise their performance. The results are recorded in CSV files and used to create tables and graphs. The overall aim is to identify the performance differences between traditional cryptographic algorithms and newer post-quantum cryptographic algorithms.

Benchmarking Methodology
Each cryptographic operation was measured using Python's `time.perf_counter_ns()` function. This function records the time taken by an operation in nanoseconds. Most operations were performed 101 times, while RSA key generation was performed 21 times. The first measurement was treated as a warm-up run and excluded from the statistical calculations. The median was used to represent the typical execution time, while the interquartile range (IQR) was used to show the variation between measurements. The results were saved in CSV format for further analysis and presentation in tables and graphs. 

Key Establishment Algorithms
Key establishment allows two parties to create or exchange a shared secret that can later be used to encrypt information. The project benchmarks several key establishment algorithms, including traditional RSA and elliptic-curve algorithms, alongside the newer post-quantum ML-KEM algorithms.
The algorithms tested in the project include:
- RSA-OAEP-3072        - RSA-OAEP-7680
- ECDH-P-256           - ECDH-P-384
- ECDH-P-521           - X25519
- ML-KEM-768           - ML-KEM-1024
Three operations were measured for each algorithm within my code:
Key generation: Measuring the time required to generate a key pair.
Encapsulation: Measuring the time required to establish or produce a shared secret.
Decapsulation: Measuring the time required to recover or calculate the shared secret.

Authenticated Encryption Algorithms
Authenticated encryption provides confidentiality and integrity. It protects the contents of a message while also allowing the recipient to detect whether the encrypted data has been modified.
The project benchmarks four authenticated encryption algorithms:
- AES-128-GCM
- AES-256-GCM
- ChaCha20-Poly1305
- AES-256-GCM-SIV
Each algorithm was tested using four different message sizes:
- 64 bytes			          - 1,024 bytes
- 16,384 bytes			      - 1,048,576 bytes
Two operations were measured by my code:
Encryption: Measuring the time required to encrypt a message.
Decryption: Measuring the time required to decrypt an encrypted message.
